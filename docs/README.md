# Documentation

This documentation describes Inlay's runtime boundaries and records the
profile-specific evidence available for the v0.1.0 release. Historical study
records are linked to their source files at the [v0.1.0 tag](https://github.com/pranavsinghpatil/inlay-mware/tree/v0.1.0/docs).

## Start here

- [Research evidence ledger](research/README.md): study status, findings,
  scope, and current release eligibility.
- [Evidence-readiness calibration](../research/evidence-readiness/v1/README.md):
  frozen artifacts, calibration results, and the review hold.
- [Changelog](../CHANGELOG.md): release contents and limitations.

The release evidence is profile- and task-specific. Historical records remain
linked to preserve negative and inconclusive results. The ledger distinguishes
whether a study ran as planned, what its evidence supports, and whether a
mechanism is eligible for release.
